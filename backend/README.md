# Pharma ERP Backend

## Setup

1. `cd backend`
2. `npm install`
3. `npm start`

## API Endpoints

- `POST /api/auth/login`
- `GET /api/medicines`
- `POST /api/medicines`
- `PUT /api/medicines/:id`
- `DELETE /api/medicines/:id`
- `GET /api/suppliers`
- `GET /api/customers`
- `GET /api/orders`
- `POST /api/orders`

The server stores data in `backend/db.json`.
